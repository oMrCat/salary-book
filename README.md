# 薪资记录账本

一款**本地运行**的薪资记录与对账软件，帮打工人记录每日工作、自动算工资，发工资时用来对账，一目了然。
**Windows 桌面版 + Android 手机版**，两端可通过同一 WiFi 一键同步，也可以导出/导入 JSON 文件互通。

## 快速使用

### Windows 版
- 双击 `dist\薪资记录账本.exe` 即可运行，无需安装任何环境。
- 数据保存在软件目录下 `data\salary.db`（SQLite），完全本地、离线、私密。

### Android 版
- 安装包：`apk\薪资记录账本.apk`（直接安装即可，最低支持 **Android 8 (API 26)**）。
- 数据保存在手机本地（SQLite），不联网、不上传。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 工作记录 | 计时/计件/加班/出勤四种类型，一键上下班打卡，节假日标记，搜索 |
| 工资规则 | 时薪、日薪、计件单价、加班/节假日倍数、发薪日、公司名 |
| 扣款记录 | 请假/迟到/社保/公积金等，自动计入应发 |
| 月度对账 | 自动汇总应发，登记实发后显示差额并红绿高亮，一键复制对账结果 |
| 统计图表 | 柱形图/折线图/饼图可切换，近 12 个月收入/应发趋势，年度汇总与年度报表导出 |
| 数据导入导出 | 支持 **Excel(.xlsx)** 和 JSON 文件导入导出（两端互通、合并导入） |
| 数据同步 | 两端同 WiFi 自动发现设备（类似 LocalSend），点设备即可拉取/推送；JSON 导入/导出 |
| 数据安全 | 启动密码保护、数据库一键备份/恢复、全部数据导出 CSV |

## 计薪规则

| 记录类型 | 计算方式 | 适用 |
| --- | --- | --- |
| 计时 | 时长(小时) × 时薪 | 按小时计薪 |
| 计件 | 件数 × 计件单价 | 按件计薪 |
| 按天 | 天数 × 日薪（留空默认1天） | 按天/日结工资 |
| 按月 | 月数 × 固定月薪（留空默认1月） | 月薪族一键录入整月工资 |
| 加班 | 时长(小时) × 时薪 × 加班倍数；勾选「节假日」× 节假日倍数（默认3） | 加班费 |

- 某条记录单独填了「单价」则优先使用记录内单价
- 月度应发 = 收入合计 − 扣款合计；差额 = 实发 − 应发
- 表单会根据所选类型自动切换提示：「选计时显示时长、选按天显示天数、选按月显示月数」

## 手机与电脑同步数据（类似 LocalSend，自动发现设备）

两端软件连**同一 WiFi** 时会**自动互相发现**，无需手动输入 IP/端口/配对码。打开「数据同步」页即可看到设备列表，点设备旁的 **拉取 / 推送** 即可同步（两台设备可互相拉取/推送）。

### 操作步骤
1. **电脑**：打开「数据同步」→ 点 **「启动同步服务」**（首次会弹防火墙提示，请允许）。
2. **手机**：打开 App →「设置」→「数据同步」，稍候自动出现电脑设备名，点 **拉取** 或 **推送**。
3. 想从电脑反向拉取/推送手机数据：电脑「数据同步」页设备列表里选中手机 → 点 **拉取/推送**。

### 技术说明
- **自动发现**：UDP 广播（255.255.255.255 + 子网广播）+ 每 10 秒网段主动探测，跨路由器/AP 隔离也能发现。
- **数据传输**：两端各自运行轻量 HTTP 服务（手机端端口自动分配），点设备后经 HTTP 传输。
- **手动备选**：自动发现失败时，两端都提供「手动连接」（IP + 端口）兜底。
- **安全**：数据仅在本地局域网传输；同步需你在设备列表中主动点击并确认，不会偷偷推送。

### JSON / Excel 文件互传（无 WiFi 时）
- Windows「数据同步」页可 **导出/导入 Excel(.xlsx)** 和 **导出/导入 JSON**；
- 手机「设置 → 数据同步」同样支持 **导出/导入 Excel** 和 **导出/导入 JSON**，通过微信/QQ/USB 与电脑互传。
- Excel 与 JSON 导入均为**合并导入**（相同去重、不同追加），两端文件格式互通。

### 同步规则：智能合并，不会丢数据
同步/导入采用**合并**方式，而不是覆盖：
- **完全相同**的记录 → 自动去重，不会重复添加
- **不同/新增**的记录 → 自动追加，双方独有的数据都会保留
- 发薪记录按月份去重：相同跳过，不同则更新
- 同步完成后会提示「新增 X 条、相同 Y 条」，可确认合并结果

## 源码运行 / 构建

### Windows 源码
```bash
pip install -r requirements.txt
python main.py
```

### Android 工程（Kotlin + Jetpack Compose）
- 工程位于 `android/`，用 **Android Studio** 打开即可运行/打包 APK。
- 命令行构建（本机已验证，JDK 需 17+，SDK compileSdk 37）：
  ```bash
  cd android
  gradlew assembleDebug      # 产物：android/app/build/outputs/apk/debug/app-debug.apk
  ```
- 关键配置：`minSdk 26`（Android 8 起）、`targetSdk 37`、AGP 9.3.1、Kotlin 2.2.10、Compose BOM 2026.02.01。
- 本机构建如果走代理（如 TrojanX），`android/gradle.properties` 已内置代理配置，端口变化请自行修改。

### 重新打包 Windows exe
```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name "薪资记录账本" ^
  --hidden-import openpyxl --hidden-import openpyxl.cell._writer main.py
```

## 目录结构
```
worker-pay/
  main.py                      # Windows 入口
  salary_app/                  # Windows 源码（db/calc/ui/excel/csvio/sync/lanserver/discovery）
  android/                     # Android 工程（Kotlin + Compose）
  apk/薪资记录账本.apk         # Android 安装包
  dist/薪资记录账本.exe         # Windows 安装包
  data/                        # Windows 本地数据（SQLite）
```

## 备注
- CSV 为 UTF-8 编码，用 Excel 打开请选择「数据 → 自文本 → 导入」。
- 建议每月发工资后到「数据同步」做一次备份。
- 局域网同步时手机与电脑必须连**同一个 WiFi**（或同一局域网）。
